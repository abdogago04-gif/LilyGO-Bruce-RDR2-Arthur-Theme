# 🤠 Red Dead Redemption 2 Theme for LilyGO (Bruce Firmware)

A custom, high-detail Arthur Morgan theme designed from scratch for the LilyGO T-Embed running **Bruce Firmware**.

![Preview](preview.gif)

## ✨ Features
- Custom artwork styled after *Red Dead Redemption 2*.
- Optimized palette matching the device's RGB backlight.
- Complete set of module banners (Wi-Fi, BLE, RF, LoRa, IR, etc.).

## ⚡ Quick Install Guide
1. **Download:** Click the green **`<> Code`** button at the top, then choose **`Download ZIP`**.
2. **Extract:** Unzip the downloaded file on your PC.
3. **Copy to SD Card:**
   - Plug your LilyGO MicroSD card into your computer.
   - Go to your themes folder on the SD card (e.g. `/themes/`).
   - Create a folder named `RDR2_Arthur`.
   - Copy all `.png` files and `Theme_RDR2.json` into that folder.
4. **Apply:** Put the SD card back into your LilyGO, go to **Settings > Display & UI**, and select the theme.
